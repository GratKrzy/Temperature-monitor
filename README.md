A small project I made for monitoring temperature in my room.
It uses an arduino uno, a dht22 temperature sensor, three thermistors and a photoresistor.
the image contains a schematic on how I connected everything.
Dataformat contains the info on how the data from a reading is stored.
Datalog has some data I gathered frome it as an example.
the .ino file contains the program for arduino.
the .py file contains the program I wrote to analyse the data.
